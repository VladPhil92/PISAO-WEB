# PISAO-WEB — repositorio histórico retirado

Este repositorio ya no es una fuente activa de desarrollo ni de producción.

La aplicación vigente de PISÁO Gastrobar continúa exclusivamente en:

- Repositorio canónico: `VladPhil92/pisao-gastrobar`
- Rama de producción: `main`
- Hosting de producción: Render
- Dominio canónico: `https://pisaogastrobar.com`

## Motivo de la consolidación

`pisao-gastrobar` nació a partir de un snapshot de este proyecto y después acumuló
la línea de desarrollo activa: identidad visual actual, menú y fotografías actuales,
CTG One, Concierge IA, analítica, operaciones de reservas y endurecimiento de
producción.

El código de esta rama se retiró para evitar dos fuentes de verdad. El historial Git
anterior permanece recuperable hasta que el repositorio sea eliminado definitivamente
desde la configuración de GitHub.
